## 使い方

鍵は本人が作る（https://elevenlabs.io → API Keys）。無料の口座で足りる（月 10,000 クレジット）。

```bash
# 1. 鍵を .env に 1 行（本体の .env でよい）
#    ELEVENLABS_API_KEY=...

# 2. 口座の枠と、使える声を見る
node eleven_voices.mjs --usage
node eleven_voices.mjs --list

# 3. 何本・何文字になるかを見てから、作る
node bench_tts.mjs --probe
node bench_tts.mjs --probe --go

# 4. 聴く（名前を伏せて → 一番を選ぶ → 答え合わせ）
node bench_tts.mjs --serve
```

ワークツリーで動かすときは、本体の `.env` を指す: `node --env-file=../../../.env bench_tts.mjs …`

ゲームの声ごと替えて遊ぶなら `.env` に次の 2 行。消せば Gemini に戻る。

```
TTS_PROVIDER=elevenlabs
PREWARM_SFX=0
```

- `PREWARM_SFX=0` を付けないと、起動時に一言・冒頭・結末の 29 本を作り直す（**送る文字数 2,099 字**。無料の枠の 2 割）。
- 声は `ELEVENLABS_VOICE_ID`。無ければ既製の声から自動で選ぶ（女性 → 日本語で確かめ済みの声 → 先頭）。Gemini で設計した声 D は使えない。
- 公開版（Cloud Run）は Gemini のまま。無料の口座の音は商用に使えず、出典の表示も要る。

## 今の声の実測（9/29 昼・11 本）

同じ台詞を Gemini 3.8 Flash TTS（声 D）・同 Lite・GPT-4o mini TTS（声 sage）・Irodori-TTS（手元）に読ませた。音は `bench/`（MP3・音量をそろえたもの。元の音量は表の数字で）、頁は `bench/index.html`、細目は `bench/results.md`。

| 口 | 最初の音まで（中央） | 同（最大） | 全部届くまで（中央） | 無音の割合 | 音量 | 1 本あたり |
|:--|--:|--:|--:|--:|--:|--:|
| Gemini 3.8 Flash TTS | 1,623 ms | 3,554 ms | 5,154 ms | 45 % | -25.3 dB | 0.177 円 |
| Gemini 3.8 Flash-Lite TTS | 1,133 ms | 2,664 ms | 4,219 ms | 51 % | -24.3 dB | 0.140 円 |
| GPT-4o mini TTS | 1,123 ms | 1,894 ms | 1,931 ms | 50 % | -30.6 dB | 0.208 円 |
| Irodori-TTS v4.1-Small（手元の PC） | 2,050 ms | 3,950 ms | 2,050 ms | 54 % | -14.1 dB | 電気代 |

- Irodori は手元の GPU（8 GB）で動かした。声は説明文から作り、参照音声は使っていない。流しながらは返せないので、「最初の音まで」は合成が終わるまでの時間（モデルの読み込みを除く）。1 本ごとに起動し直すと、読み込みを含めて 1 本 約 18 秒。常駐させれば 62 秒ぶんの音を 27 秒で作る速さ。
- Irodori は音が大きい（他より 10 dB ほど）。11 本のうち 3 本は山が 0 dB に届いていて、割れているかもしれない。
- Irodori には親しさを渡していないので、`calm_low` と `calm_high` は同じ音。
- 「最初の音まで」には日本からの通信の時間が入っている。1 本ずつ・1 回だけの値なので、ばらつきは見ていない。
- 無音は「大きいところから 30 dB 下が 0.1 秒以上続いたところ」。冒頭（`opening`）は 13.08 秒・無音 6.08 秒・いちばん長い間 0.98 秒。
- 「ひゃっ！」（`hya`）は Flash で 0.48 秒。9/27 の 0.64 秒より短い。聴いてどうかは未確認。
- **良し悪しは測っていない**。聴くのは本人。

## Eleven v4 を作って分かったこと（9/29 昼すぎ・測った値と機械の聞き取り）

声は既製の Sarah（英語の話者）。鍵に声の一覧を読む許可が無く、選べなかったため。**声 D とは別人**なので、声質ではなく読み方・間・演技を聴く。

| 口 | 最初の音まで（中央） | 同（最大） | 全部届くまで（中央） | 無音の割合 | 音量 | 1 本あたり |
|:--|--:|--:|--:|--:|--:|--:|
| Eleven v4 | 1,143 ms | 1,372 ms | 1,535 ms | 33 % | -21.0 dB | 0.407 円 |
| Eleven v4 Turbo | **209 ms** | 868 ms | 498 ms | 32 % | -21.9 dB | 0.203 円 |

- **v4 Turbo は、日本から測っても最初の音まで 0.2 秒。** Gemini Flash（1.6 秒）の 8 分の 1。公式の 150 ms（通信を除く）と合う。
- 冒頭（`opening`）は 10.4 秒・無音 3.3 秒。Gemini Flash は 13.1 秒・無音 6.1 秒。「……」はそのまま渡している。
- 無料の口座で、v4 も v4 Turbo も API から読めた。`language_code: "ja"` も通った。
- 料金は送った文字数どおり（応答の `character-cost`）。**指示の `[ ]` も数えられる。** v4 Turbo は半分。

指示の書き方は 4 通り試した。採ったのは「短い」。

| 書き方 | 例 | 結果（機械の聞き取り） | 判定 |
|:--|:--|:--|:--|
| 長い英語（最初の案） | `[frightened but refusing, low, slightly trembling, clear, …]` | **言葉をくり返す。**「やめてください」が 2〜4 回、「ふふ」が 3〜5 回、「ひゃ、ひゃ、ひゅう」。「片付け」を「きたづけ、片づけ」と言い直す。短い台詞ほど出る | ボツ |
| 日本語（Gemini と同じ文） | `[恥ずかしそうに、少し早口で。…]` | **指示を読み上げた**（冒頭が 18.4 秒になり、「長い沈黙はいらない。意思表示は曖昧で…」から始まる） | ボツ |
| なし | | くり返しは出ない | 保留（演技が付くかは聴いて） |
| 短い英語（1〜2 語） | `[shy]` `[upset, quiet]` | くり返しは出ない。費用も小さい（11 本で 373 字。長い英語は 1,208 字） | **採用（既定）** |

機械の聞き取りで引っかかった点（短い指示でも残ったもの。聴いて確かめる）:

| 台詞 | 口 | 聞き取り |
|:--|:--|:--|
| `calm_high` | v4 | 「着たづけ、続けますね。」（片付け） |
| `calm_low` | v4 Turbo | 「きたづけ、続けますね。」 |
| `wings` | v4・v4 Turbo | 「少し震えてます」「超、震えてます」（手、震えてます） |
| `perfect` | v4 Turbo | 「今夜さん」（本屋さん） |
| `hya`・`fufu`・`a_strong` | どの口も | 1 秒より短い音は、機械がうまく聞き取れない（Gemini でも空や別の言葉になる）。ここは耳だけが頼り |

- 聞き取りは目安。読み違いなのか、聞き取りの間違いなのかは、聴かないと分からない。
- 9/27 の「……」の無音は、v4 では起きていない。代わりに「頭の 1 語の読み」が怪しい。どちらも台詞の頭が「……」の行。

## 本人が画面で聴いた結果（9/29・ライブラリの日本語の声 2 つ × Eleven v4）

ElevenLabs の画面の読み上げで、本人が選んだ日本語の声 2 つ（API からは 402 で使えなかったもの）を試した。

> 良くも悪くも素人の声が生々しく台詞になってる。つまり、入力に対する再現度は高い。アニメやゲームなどのフィクション・2次元にどう合うかは別として。（本人）

- 読み取れること（Claude の見立て）: ライブラリの声は、実在の人が自分の声を登録したもの。v4 が元の声をよく写すなら、アニメらしさはモデルではなく、元の声で決まる。9/27 の「かわいさは声質で決まり、プロンプトでは変わらない」と同じ向き。
- 残る道は、声を文章から作る（Voice Design）。Gemini で声 D を作ったのと同じやり方。無料の口座で API から使えるかは未確認。

## 分かったこと

- **演技の指示が、台詞より長い。** ElevenLabs は文字数で数え、指示（`[ ]` の中）も文字数に入る（未実測・公式の料金の説明から）。

  | | 台詞だけ | 指示つきで送る文字数 |
  |:--|--:|--:|
  | 一言 19 本 | 90 字 | 1,131 字 |
  | 冒頭・結末 10 本 | 476 字 | 968 字 |
  | 聞き比べの 11 本 | 228 字 | 1,208 字 |

  Gemini は指示を別の欄で渡し、料金は音の長さで決まる。短い台詞が多いこのゲームでは、指示の長さがそのまま費用になる。`tag=none`（指示なし）で足りるかを先に聴く。
- 音の形は同じ（生の PCM・16bit・24 kHz・モノラル）。画面側は直さずに鳴る。
- 画面側は Gemini の小さめの声に合わせて 2.6 倍している。大きすぎたら `ELEVEN_GAIN` で下げる（聞き比べの表の「音量」を見て決める）。

## 採らなかった案と理由
